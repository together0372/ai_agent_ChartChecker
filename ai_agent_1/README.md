# 차트 왜곡 탐지 시스템

뉴스/보고서 차트 이미지를 분석해 시각적 왜곡·조작을 자동으로 탐지하는 멀티에이전트 시스템.

---

## 설치

### 1. Ollama 설치 및 모델 다운로드
```bash
# https://ollama.com/download 에서 Ollama 설치 후
ollama pull qwen3:9b
```

### 2. 패키지 설치
```bash
pip install -r requirements.txt
```

---

## 사용법

### 1. 분석할 이미지 준비
`ai_agent/test/` 폴더에 차트 이미지를 넣습니다.
```
ai_agent/
└── test/
    ├── chart1.png
    ├── chart2.jpg
    └── ...
```
지원 형식: `.png` `.jpg` `.jpeg` `.webp` `.bmp`

### 2. 실행
```bash
cd ai_agent
python main.py
```

### 3. 결과 확인
```
✅ [chart1.png] 최종 판정: 정상
❌ [chart2.png] 최종 판정: 오류
  🚨 발견된 오류 1개:
    • Y축 절단
      Y축이 0이 아닌 값에서 시작해 차이를 과장함
```

---

## 주요 설정

`main.py` 상단에서 변경 가능합니다.

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `USE_VECTOR_DB` | `True` | RAG 벡터DB 사용 여부 (False시 속도 향상) |

`agents/core/config.py`에서 모델 변경 가능합니다.

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `LLM_NAME` | `qwen3:9b` | Ollama 모델명 |

---

## 탐지 가능한 오류 유형

| 유형 | 설명 |
|------|------|
| Y축 절단 | Y축을 0이 아닌 값에서 시작해 차이 과장 |
| 이중 축 조작 | 무관한 두 변수를 이중 Y축으로 상관관계처럼 보임 |
| 선택적 강조 | 특정 값만 색상·주석으로 부각 |
| 비대칭 눈금 | 양방향 막대 차트의 좌우 축 스케일 불일치 |
| 파이 각도 왜곡 | 파이/도넛 슬라이스 각도가 실제 비율과 불일치 |
| 데이터 공백 | X축 일부 구간(연도 등) 생략 |
| 로그 축 미표기 | 로그 스케일임을 표시하지 않음 |
| 기타 | 화면비 왜곡, 역방향 축, 버블 면적 왜곡 등 |

---

## 시스템 구조

```
이미지 입력
  → 차트 판별 (차트가 아니면 스킵)
  → 관찰자 에이전트 (도구 호출로 수치 검증)
  → 수학 검증 (이미지에서 숫자 추출 후 계산)
  → 토론 에이전트 (반박자 vs 관찰자 1회)
  → 자기비판 검증 (필요시 재검토)
  → 최종 판정 출력 (정상 / 경고 / 오류)
```
