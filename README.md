## ⚙️ 사전 준비 사항 (Prerequisites)

본 테스트 환경은 Visual Studio Code(VS Code)와 확장 프로그램인 **Live Server**가 필요합니다.

1. [VS Code](https://code.visualstudio.com/)가 없다면 설치해 주세요.
2. VS Code 좌측 메뉴의 **확장(Extensions)** 탭에서 `Live Server` (제작자: Ritwick Dey)를 검색하여 설치합니다.

---

## 🚀 실행 및 설치 방법 (How to Run)

본 시연은 **1) 크롬 익스텐션 로드**, **2) 실험용 대시보드 실행** 두 단계로 진행됩니다.

### Step 1. 크롬 익스텐션 로드하기

1. 크롬 브라우저 주소창에 `chrome://extensions/`를 입력하여 확장프로그램 관리 페이지로 이동합니다.
2. 우측 상단의 **[개발자 모드]** 토글을 켭니다 (파란색 활성화).
3. 좌측 상단의 **[압축해제된 확장 프로그램을 로드합니다]** 버튼을 클릭합니다.
4. 이 `README.md` 파일이 들어있는 **프로젝트 폴더(`chart-detector-mvp`)를 선택**합니다.
5. "ChartQuiz Demo" 확장프로그램이 정상적으로 로드되었는지 확인합니다.
* *(코드를 수정했다면 카드 우측 하단의 🔄 새로고침 버튼을 꼭 눌러주세요!)*



### Step 2. HCI News 실험 대시보드 띄우기

1. VS Code에서 `index.html` 파일을 엽니다.
2. VS Code 화면 우측 하단 상태 표시줄에 있는 **`Go Live`** 버튼을 클릭합니다. (또는 코드 화면 우클릭 후 `Open with Live Server` 클릭)
3. 크롬 브라우저 새 탭이 열리며 `http://127.0.0.1:5500/index.html` 주소의 **HCI News 대시보드**가 실행됩니다.

## 🎯 UX 실험 시나리오 흐름 (Demo Flow)

피실험자에게 대시보드 화면을 띄워준 후 아래의 흐름대로 행동을 관찰합니다.

1. **화면 진입 및 뱃지 등장:** 대시보드가 열리면 화면 내 4개의 기사(왜곡 2개, 정상 2개) 차트 우측 상단에 `⚙️ AI 분석 중...` 로딩 뱃지가 동시에 나타납니다.
2. **정상 차트 필터링 (1초 후):** 우측 하단 구역에 있는 정상 차트들의 로딩 뱃지는 조용히 사라지며 아무 일도 일어나지 않습니다.
3. **왜곡 차트 탐지 및 팝업 (3초 후):** 좌측 구역에 있는 2개의 왜곡 차트(동아일보, 빅카인즈) 뱃지가 사라지며, 하단에 🚨 **`숨겨진 진실 퀴즈` 팝업 배너**가 등장합니다.
4. **유저 태스크 (Task):**
* 피실험자가 배너의 'O' 버튼을 눌러 퀴즈 화면에 진입합니다.
* 퀴즈를 풀고 정답 및 **AI 해설**을 확인하여 시각적 왜곡(Visual Reveal)을 인지하는지 관찰합니다.
* 필요시 각 카드의 하단 `🔗 원본 기사 보기`를 클릭해 실제 맥락을 확인하게 유도할 수 있습니다.
